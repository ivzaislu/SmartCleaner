# SmartCleaner 2.0.2 — обновления драйверов

Откройте «Драйверы» и нажмите «Проверить обновления». SmartCleaner читает версии установленных драйверов и запрашивает применимые предложения у службы Windows Update, настроенной в системе. Для сопоставления используются идентификаторы оборудования и совместимости. Если предложение найдено, но сопоставить его с записью локального устройства не удалось, оно остаётся в списке.

Номер версии отображается, когда он присутствует в официальном названии предложения. Отдельно отображается дата драйвера, которую возвращает Windows Update. Список зависит от версии Windows, оборудования и политики обновлений. [Поля Windows Update Agent](https://learn.microsoft.com/en-us/windows/win32/wua_sdk/iwindowsdriverupdate-properties)

Выберите строку и нажмите «Перейти к обновлению выбранного». SmartCleaner показывает название пакета и открывает «Необязательные обновления», где можно выбрать драйвер и запустить установку. [Разделы настроек Windows](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings)

Сборка выполняется по инструкции WINDOWS-2.0.1.md. Для нового портативного файла используйте имя SmartCleaner-2.0.2-Portable.
