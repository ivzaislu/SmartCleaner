# Драйверы Windows 10/11: источники и уровни проверки

## Что SmartCleaner умеет проверять автоматически

**Windows Update Agent (WUA)** — единственный источник автоматических
предложений, загрузки и установки драйверов непосредственно в SmartCleaner.
WUA ищет пакеты, которые считает применимыми к данной системе и её политике
Windows Update / WSUS. Предложение WUA **не гарантирует**, что это самая
последняя версия с сайта производителя и что её стоит ставить на любой ПК.

SmartCleaner запоминает идентификатор и ревизию предложения WUA, повторно
запрашивает применимость перед загрузкой и установкой. Удержание кнопки 1500 мс
запускает **только загрузку** через WUA; для установки требуется отдельное
подтверждение. Неизвестные, неподписанные внешние EXE и прямые URL не загружаются.

## Внешние официальные инструменты

SmartCleaner распознаёт оборудование по PCI/USB Vendor ID, показывает
установленную версию драйвера и предоставляет ссылки на следующие
**официальные** средства:

| Производитель | Способ проверки | Возможность SmartCleaner |
|---|---|---|
| NVIDIA GeForce | [NVIDIA App](https://www.nvidia.com/en-us/software/nvidia-app/) | Открыть официальный сайт инструмента |
| AMD Radeon / Ryzen | [AMD Auto-Detect and Install](https://www.amd.com/en/resources/support-articles/faqs/GPU-131.html) | Открыть официальную инструкцию / инструмент |
| Intel | [Intel Driver & Support Assistant](https://www.intel.com/content/www/us/en/support/detect.html) | Открыть официальный сайт инструмента |
| Realtek | [Realtek Downloads](https://www.realtek.com/download/list) либо производитель ПК/платы | Ручная проверка |
| Broadcom / Qualcomm / Creative | Официальный сайт производителя или OEM | Ручная проверка |
| MediaTek и неизвестные | OEM-портал устройства (если известен) | Ручная проверка |
| Dell / HP / Lenovo / ASUS / Surface | Официальные страницы поддержки конкретной модели ПК | Ручная проверка |

**Важно:** у SmartCleaner нет документированного публичного интерфейса для
получения результата проверок NVIDIA App, AMD Auto-Detect или Intel DSA.
Ссылки **не** означают, что эти инструменты установлены или запущены, и не
являются подтверждением более новой версии. Не используются парсинг HTML
скачивания, неофициальные API, зеркала или запуск произвольных EXE.

OEM-драйверы на ноутбуках могут содержать специфические настройки графики,
звука, питания и сетевых модулей. Для Realtek встроенного аудио производитель
советует брать OEM-драйвер, поскольку универсальный может лишиться настроек.

## Отображаемые статусы

- `WUA_NEWER`: есть применимый пакет WUA, и **формат версий сопоставим**;
  числовой номер WUA выше установленного. Это не обещание «самой новой» версии.
- `WUA_OFFER`: WUA предлагает пакет, но корректное сравнение версий не доказано.
- `WUA_NOT_NEWER`: WUA предлагает применимый пакет, но сравнимый номер не выше.
- `INCOMPLETE`: WUA сообщил о частично успешной проверке; нельзя делать вывод
  об отсутствии обновлений.
- `VENDOR_ASSISTANT`: у производителя есть официальный инструмент проверки,
  но его результат не получен SmartCleaner.
- `MANUAL`: есть официальный сайт, свежесть драйвера на нём не проверена.
- `UNKNOWN`: нет подтверждённого источника и актуальность неизвестна.

## Проверки перед релизом

Нужны реальный Windows 10/11, штатная и управляемая WSUS-конфигурации,
включённые/отключённые устройства, виртуальные и физические PCI/USB устройства,
несопоставимые версии драйверов, ошибки/отмена загрузки, запрос UAC, перезагрузка
и восстановление системы. CI с имитацией Windows API не заменяет это.
